# Терминал НИО: памятка

Получите логин и пароль у главы НИО. Учётная запись уже создана при вашем прибытии. Глава НИО получает бумажный реестр; поздние прибытия приходят ему в почту КПК. Капитан и глава персонала получают свои реквизиты в приложении «Почта станции».

После входа можно работать с картой или командной строкой. Обычные сотрудники могут просматривать базу и почту. Исследования доступны учёным, управление доступом — руководителям. Для работы достаточно открытой сессии: чужие реквизиты или оставленный терминал тоже дают доступ.

## Исследования

| Команда | Действие |
|---|---|
| `help` / `help science` | Справочник и примеры |
| `find схемы` | Найти технологии по слову |
| `info electronics` | Цена, требования, результат |
| `plan precisionelectronics` | Недостающая цепочка до цели и общая цена |
| `research electronics` | Изучить технологию за обычную стоимость |
| `batch electronics,automation` | Выполнить несколько по порядку, пока хватает очков |
| `queue plan precisionelectronics` | Поставить недостающую цепочку в очередь |
| `queue add metallurgy` | Добавить одну технологию |
| `queue list` / `queue cancel` | Посмотреть / снять оставшиеся задания |

Можно использовать полный идентификатор технологии, её точное название или короткое имя, которое показывает `find`. Tab дополняет ввод, стрелки возвращают историю. Несколько команд разделяются `;`, максимум восемь за один ввод.

Очередь ждёт очков и предпосылок, не пропускает исследования и не даёт скидок. Научные образцы также изучаются через консоль с открытой сессией учёного. Для передачи завершённых технологий инженерии держите диск в руке и нажмите «Записать диск», затем загрузите его в нужные машины.

## Научный анализ

`analyze electronics` запускает проверку доступной, ещё не изученной технологии. Прибор показывает три сигнала: выберите самый сильный через `trace B`. Затем вычислите разницу между эталоном и измерением, например `tune 13`. На последнем шаге сложите три шестнадцатеричных байта по модулю 256 и отправьте `verify XX` с полученной суммой.

Успех приносит сети 100–600 научных очков один раз на технологию. Исследование всё равно нужно приобрести. Ошибка прерывает проверку и требует 45 секунд на восстановление. На прохождение даётся три минуты.

## Сеть, сотрудники и почта

| Команда | Действие |
|---|---|
| `status` / `whoami` | Сессия, права, сервер и очки |
| `servers` / `connect rd-2` | Найти сервер / подключить консоль |
| `terminals` | Терминалы текущего научного сервера и открытые сессии |
| `remote lab-3 status` | Проверить терминал |
| `remote lab-3 exit` | Закрыть собственную сессию; руководитель может закрыть чужую |
| `users Смирнова` | Найти сотрудника и логин |
| `mail inbox` / `mail read 1` | Список писем / прочитать письмо |
| `mail send crew007 Нужен образец сплава` | Отправить игровое письмо |
| `history` / `clear` | История команд / очистить экран |

Руководителям доступны `role crew007 observer|researcher|admin`, `reset crew007` и `revoke crew007`. Новый пароль после сброса приходит в почту руководителя; старые сессии сотрудника закрываются. Пароль не выводится в общий журнал команд. Письмо, открытое через `mail read`, останется на экране терминала, пока его не очистят.

## Как закончить работу

**Esc** закрывает окно, оставляя сессию и очередь включёнными. Оставленным терминалом может воспользоваться другой сотрудник.

**`exit`** завершает сессию, останавливает очередь и закрывает окно. Потеря питания тоже завершает сессию. Не оставляйте открытой сессию руководителя без присмотра.

В настройках интерфейса можно включить открытие поддерживаемых окон на весь экран приложения. Кнопка CRT внизу консоли отключает эффекты экрана. Вблизи карта показывает полные карточки, при отдалении — короткие подписи без миниатюр. Масштаб ограничен читаемым размером. Колесо меняет масштаб, перетаскивание фона перемещает камеру, «К узлу» возвращает к выбранной технологии, «Начало ветки» открывает первые узлы раздела. Для перехода к разработке используйте реестр слева или ссылки в досье.


## Реестр разработок и специализации — 29 октября 2026

Ищите по названию исследования, станка, модуля, изделия или жидкости. Поиск охватывает все разделы. Фильтр статуса отделяет отсутствие предварительных исследований от нехватки очков. Выберите результат в реестре, затем «Путь к выбранной цели»: карта покажет только зависимости, а под реестром появится оставшаяся стоимость. «В очередь исследований» добавляет цель вместе с недостающими разработками; очки списываются по мере их поступления.

Карта сохраняет читаемый масштаб. Большие ветки перемещаются мышью; выбор в реестре и переходы в досье возвращают к нужному узлу. У каждого раздела собственная раскладка, обновление очков её не меняет.

Промышленность разделена на 14 дополнительных специализаций с работающими рецептами. Подробности и следующие предложения: [навигация и развитие](research-navigation-and-development.ru.md).
