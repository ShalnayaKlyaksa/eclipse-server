# Гайд: как создавать уроки обучения (Eclipse Tutorial)

Этот документ описывает формат уроков обучения: из чего состоит урок, какие бывают шаги
(диалоги, спотлайты, задания), триггеры и анимации. Уроки **data-driven** — новый урок
создаётся правкой YAML, без C#.

> **Внимание — статус реализации.** Часть возможностей ещё в разработке. Смотрите таблицу
> статуса ниже: не используйте поля со статусом «планируется», пока соответствующий этап не готов —
> они пока не работают. Формат зафиксирован, чтобы уроки, написанные сейчас, заработали без переписывания.

## 2. Быстрый старт: минимальный урок

```yaml
- type: tutorialLesson
  id: TutorialIntro
  name: Вступление
  description: Знакомство с интерфейсом и управлением.
  icon: /Textures/Interface/VerbIcons/examine.svg.192dpi.png
  order: 0
  map: /Maps/_Eclipse/Tutorial/intro.yml   # 🚧 D2
  steps:                                     # 🚧 D3+
    - !type:Dialogue
      speaker: Инструктор
      text: "Добро пожаловать на станцию!"
```

`id` уникален, `order` задаёт позицию в списке (меньше — выше). `enabled: false` покажет урок
в списке, но кнопкой «Скоро» (нельзя запустить) — удобно для незаконченных уроков.

## 3. Поля прототипа урока

| Поле | Тип | Обяз. | Статус | Описание |
|---|---|---|---|---|
| `id` | строка | да | ✅ | Уникальный идентификатор урока. |
| `name` | строка | да | ✅ | Название в списке. |
| `description` | строка | нет | ✅ | Короткое описание под названием. |
| `icon` | путь текстуры | нет | ✅ | Иконка урока. |
| `order` | число | нет | ✅ | Порядок в списке (по возрастанию). |
| `enabled` | bool | нет | ✅ | `false` — урок виден, но недоступен. По умолчанию `true`. |
| `map` | путь карты | нет | 🚧 D2 | Грид обучения, который загружается игроку. Если не указан — создаётся пустой грид. |
| `body` | id прототипа | нет | 🚧 D2 | Прототип тела игрока в обучении. По умолчанию — учебный персонаж. |
| `steps` | список шагов | нет | 🚧 D3+ | Последовательность шагов урока (см. ниже). |

## 4. Шаги урока (`steps`) — модель

`steps` — это **последовательность**, которая проигрывается сверху вниз. Каждый шаг —
это объект с тегом `!type:<ТипШага>`.

Есть два вида шагов:

- **Ждущие** — обучение останавливается на шаге, пока условие не выполнится
  (игрок кликнул диалог / выполнил задание / истёк таймер). Это `Dialogue`, `Task`, `Wait`.
- **Мгновенные** — меняют состояние и сразу переходят к следующему шагу.
  Это `Spotlight`, `ClearOverlays`, `Teleport`, `Spawn`, `GiveItem`.

**Оверлеи держатся между шагами.** Спотлайты и затемнение экрана остаются на экране, пока их
не заменит новый `Spotlight` или не уберёт `ClearOverlays`. Это позволяет писать линейно:

```yaml
steps:
  - !type:Spotlight            # подсветили здоровье (мгновенно, остаётся на экране)
    rects:
      - screen: [0.85, 0.9]
        size:   [220, 120]
  - !type:Dialogue             # объяснили (ждём клик), спотлайт всё ещё виден
    speaker: Инструктор
    text: "Это индикатор здоровья."
  - !type:ClearOverlays        # убрали подсветку
```

## 5. Типы шагов

### 5.1 `Dialogue` — диалоговое окно (визуальная новелла) — 🚧 D4

Нижняя плашка с текстом и портретом персонажа на затемнённом фоне.

| Поле | Тип | По умолч. | Описание |
|---|---|---|---|
| `speaker` | строка | — | Имя говорящего (шапка плашки). |
| `text` | строка | — | Текст реплики. Поддерживает разметку (`[color=...]`, `[bold]`). |
| `portrait` | путь текстуры | нет | Портрет персонажа. Если нет — только текст. |
| `side` | `Left`/`Center`/`Right` | `Left` | С какой стороны стоит портрет. |
| `animation` | см. §7 | `None` | Анимация портрета при появлении/во время реплики. |
| `advance` | `Click`/`Auto` | `Click` | `Click` — ждать клик игрока; `Auto` — авто-переход через `delay`. |
| `delay` | число (сек) | `2` | Задержка для `advance: Auto`. |

```yaml
- !type:Dialogue
  speaker: Доктор Вейн
  portrait: /Textures/_Eclipse/Tutorial/Portraits/doctor.png
  side: Left
  animation: Bounce
  text: "Первое правило медицины — [color=#E6A11A]не навреди[/color]."
```

### 5.2 `Spotlight` — подсветка со затемнением — 🚧 D3

Затемняет весь экран, кроме заданных прямоугольников (спотлайтов). Мгновенный шаг.

| Поле | Тип | По умолч. | Описание |
|---|---|---|---|
| `rects` | список областей | — | Одна или несколько подсвеченных областей. |
| `dim` | число 0..1 | `0.75` | Насколько затемнён остальной экран. |
| `caption` | строка | нет | Подпись рядом с подсветкой. |

Область (`rect`) задаётся одним из способов:

- **Экранная** (доля экрана, `0,0` — левый верх, `1,1` — правый низ):
  ```yaml
  - screen: [0.85, 0.9]   # позиция центра, доли экрана
    size:   [220, 120]    # размер в пикселях
  ```
- **Мировая** — привязка к сущности/точке на гриде обучения (подсветка следует за объектом):
  ```yaml
  - world: [5, 3]         # координаты на гриде
    size:  [64, 64]
  ```
  либо по маркеру-имени объекта из карты:
  ```yaml
  - anchor: TutorialDoor  # имя/тег объекта из карты обучения
  ```

```yaml
- !type:Spotlight
  dim: 0.8
  caption: "Панель управления"
  rects:
    - screen: [0.5, 0.5]
      size:   [300, 200]
```

### 5.3 `Task` — задание с триггером — 🚧 D5

Показывает цель и ждёт, пока сработает триггер. Только после этого урок продолжается.

| Поле | Тип | Обяз. | Описание |
|---|---|---|---|
| `objective` | строка | да | Текст задания игроку. |
| `trigger` | триггер | да | Условие завершения (см. §6). |
| `hintDelay` | число (сек) | нет | Через сколько показать подсказку/спотлайт, если игрок застрял. |

```yaml
- !type:Task
  objective: "Возьмите шприц со стола."
  trigger: !type:PickUp
    whitelist:
      - Syringe
```

### 5.4 Вспомогательные шаги — 🚧 D5

| Шаг | Поля | Описание |
|---|---|---|
| `!type:Wait` | `delay` (сек) | Просто пауза. |
| `!type:Teleport` | `to: [x, y]` или `anchor: <имя>` | Телепортировать игрока по гриду обучения. |
| `!type:Spawn` | `proto`, `at: [x,y]`/`anchor` | Заспавнить сущность на гриде. |
| `!type:GiveItem` | `proto` | Выдать предмет в руки игроку. |
| `!type:ClearOverlays` | — | Убрать все спотлайты/затемнение/диалог. |

## 6. Триггеры (для `Task`) — 🚧 D5

Триггер — объект `!type:<ТипТриггера>`. Планируемый набор:

| Триггер | Поля | Срабатывает когда |
|---|---|---|
| `!type:ReachArea` | `position: [x,y]`, `radius` | Игрок вошёл в радиус точки на гриде. |
| `!type:PickUp` | `whitelist` (прототипы) | Игрок взял подходящий предмет в руки. |
| `!type:Interact` | `whitelist`, `anchor` | Игрок взаимодействовал с объектом (клик/использование). |
| `!type:UseItemOn` | `used`, `target` | Игрок применил предмет A на объект B. |
| `!type:PressKey` | `function` (имя bind'а) | Игрок нажал заданную клавишу/действие. |
| `!type:OpenUi` / `!type:CloseUi` | `key` | Игрок открыл/закрыл интерфейс. |
| `!type:MoveDirection` | `direction` | Игрок пошёл в заданную сторону (для урока управления). |
| `!type:Damaged` / `!type:Healed` | `threshold` | Здоровье игрока/цели пересекло порог. |
| `!type:All` / `!type:Any` | `triggers: [...]` | Комбинация: выполнить все / любой из вложенных. |

Пример комбинированного триггера (взять шприц **и** подойти к пациенту):

```yaml
trigger: !type:All
  triggers:
    - !type:PickUp
      whitelist: [Syringe]
    - !type:ReachArea
      position: [8, 4]
      radius: 1.5
```

## 7. Анимации диалога (`animation`) — 🚧 D4

| Значение | Эффект |
|---|---|
| `None` | Без анимации. |
| `Bounce` | Небольшой подскок при начале реплики. |
| `Shake` | Дрожь (испуг, тревога). |
| `SwayLeft` / `SwayRight` | Плавное смещение в сторону. |
| `Nod` | Кивок (согласие). |

Анимацию указываете вы отдельно на каждой реплике — «в зависимости от ситуации».

## 8. Полный пример урока

```yaml
- type: tutorialLesson
  id: TutorialIntro
  name: Вступление
  description: Знакомство с интерфейсом, управлением и основами станции.
  icon: /Textures/Interface/VerbIcons/examine.svg.192dpi.png
  order: 0
  map: /Maps/_Eclipse/Tutorial/intro.yml
  steps:
    # 1. Приветствие
    - !type:Dialogue
      speaker: Инструктор
      portrait: /Textures/_Eclipse/Tutorial/Portraits/instructor.png
      animation: Bounce
      text: "Добро пожаловать на борт! Я помогу освоиться."

    # 2. Учим движение
    - !type:Dialogue
      speaker: Инструктор
      text: "Двигайтесь на клавиши [color=#E6A11A]WASD[/color]."
    - !type:Task
      objective: "Пройдите вперёд."
      trigger: !type:MoveDirection
        direction: North

    # 3. Подсвечиваем здоровье и объясняем
    - !type:Spotlight
      caption: "Здоровье"
      rects:
        - screen: [0.85, 0.9]
          size:   [220, 120]
    - !type:Dialogue
      speaker: Инструктор
      animation: SwayRight
      text: "Здесь показано ваше состояние."
    - !type:ClearOverlays

    # 4. Задание: подойти к двери
    - !type:Task
      objective: "Подойдите к двери."
      trigger: !type:ReachArea
        position: [10, 5]
        radius: 1.5

    # 5. Финал
    - !type:Dialogue
      speaker: Инструктор
      text: "Отлично! Обучение завершено."
```

## 9. Советы и частые ошибки

- **`id` уникален** среди всех уроков. Дубликат — ошибка загрузки прототипов.
- **Порядок шагов важен**: `Spotlight` сам по себе мгновенный — за ним должен идти
  `Dialogue`/`Task`/`Wait`, иначе игрок не успеет увидеть подсветку.
- **Не забывайте `ClearOverlays`** после блока подсветок, иначе затемнение останется.
- **Экранные координаты** (`screen`) — доли `0..1`, а `size` — в пикселях (масштабируется вместе с UI).
- **Мировые координаты** (`world`/`position`) — это клетки на гриде обучения, смотрите их в редакторе карт.
- Тексты диалогов поддерживают разметку: `[bold]`, `[italic]`, `[color=#RRGGBB]...[/color]`.
- Пока этап не помечен ✅ в §0 — соответствующие поля не работают; можно писать урок «на будущее»,
  но проверять его в игре получится только после реализации этапа.
