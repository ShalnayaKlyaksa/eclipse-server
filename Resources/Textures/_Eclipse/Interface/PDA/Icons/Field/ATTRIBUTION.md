# Field interface icons

Microsoft Fluent UI System Icons, Regular, MIT; see ../LICENSE.txt. Exact upstream URLs are recorded in sources.json. Original SVGs are retained unchanged.

PNG exports use a project-specific pale brass gradient, with no colored application tiles. Render script: art/render-pda-field-icons.cjs.

Exception: max.svg is the original MAX logo supplied by the project owner (Логотип_MAX.svg), exported without recoloring. It is not part of the Microsoft icon set.


The Orbit messenger glyph (messenger.svg/png) is original Eclipse vector artwork, CC0-1.0. The previous user-provided MAX logo is no longer used by the messenger.

The network, access log, wanted-record and tracker glyphs (network/logs/wanted/tracker.svg/png) are original Eclipse vector artwork, CC0-1.0, exported in the same satin-metal palette.
